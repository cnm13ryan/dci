## 10. Generation engine and the synthetic oracle

The journal, batch plan, prompt cache and integrity checks carry over from v13.
Two things change.

Every generation stage now begins by restoring from the durable mirror, so a
run that resumes after a disconnect regenerates only the batch that was in
flight.

The dry-run oracle draws from a corpus composed so that each verifier's feature
varies independently, including the bridge family's sentence-level properties.
Because the selection distribution is written down rather than sampled blindly,
the induced failure rate of every design cell has a closed form, and Gate 0
asserts that the pipeline recovers the world it was given.
