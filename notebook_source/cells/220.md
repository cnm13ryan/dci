## 13. GATE 0 — implementation completeness

The notebook must behave correctly on synthetic data with a known answer before
it sees any real data. Nothing here loads a model; `load_model` itself refuses
to run until this gate and Gate M have both passed.

Beyond v13's structural, oracle and decision-rule checks, Gate 0 now tests
every v14 correction directly: that $g_0$ and $g_2$ cannot authorize a failed
$g_1$; that the pseudo-focal universe is independent of $B$; that too few
evaluable pseudo-focals returns `REFERENCE_VALIDATION_NOT_EVALUABLE` rather
than passing quietly; that a panel mean cannot conceal two references
cancelling; that a small point estimate with wide uncertainty fails Gate 4;
that an unsigned audit blocks execution and a signed one cannot be overwritten;
that held-out wordings never enter construction; that precision is judged on
contenders rather than the median; that false-fail error can fail the
measurement gate; that a foreign model profile's cache is quarantined rather
than read; that Drive restoration reproduces a deleted local cache without
regenerating anything; and that `PRECISION_INSUFFICIENT` and
`NOT_IDENTIFIED_SUPPORT` remain distinct.
