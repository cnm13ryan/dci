## 4. Model

Loading is gated. A model cannot be loaded until Gate 0 (implementation) and
Gate M (measurement validity) have both passed, which is the mechanical form of
"a verifier may not shape the reference architecture before its validity is
established".

The tokenizer and chat template are hashed at load and recorded on every
committed batch, so a cache generated under a different tokenizer or template
is rejected even though neither is knowable when the run directory is created.
