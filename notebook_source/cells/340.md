## 24. Freeze

Everything above is calibration and validation. Everything below reads
confirmatory outcomes.

The protocol fingerprint now covers every input capable of changing a generated
response, a selection, a validation or an inference: model and revision,
tokenizer and chat template, engine, dtype, attention implementation, sampling
parameters, batch size, adaptive batching, every seed tuple, task identities and
text, wording identities and text, both signed audit artifacts, verifier source,
the coupling response bank and mutation specification, the $U$ split, the
candidate pool, the feature-role table, every caliper, the selected references,
the stochastic weights, and the analysis specification.

Hardware is recorded separately and deliberately excluded, so the same protocol
run on different hardware hashes identically; the scientific run still uses one
frozen hardware and software condition.
