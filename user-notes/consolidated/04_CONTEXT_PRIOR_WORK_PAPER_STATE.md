It cannot *support* any claim: different constraint vocabulary, 20 topics, one base seed for Rounds 1–10, all stamped `EXPLORATORY_NO_EVIDENCE`, no run promoted into `exploratory/evidence/` ([`AUDIT_2026-08-23_v4r4_evidence.md`](../AUDIT_2026-08-23_v4r4_evidence.md) row 10). ### 2.3 The comparison questions a literature search must answer
1. Is generic multi-instruction degradation at load two on small open models already established (IFEval/ComplexBench/Vasileva/Anand & Chattaraj/MOSAIC/Harness-IF/Qi)? If yes, L1 is confirmation, not contribution.
2. Does any prior work estimate a companion-specific excess over a difficulty- or solo-matched control (the Δ_R construct), and how did it match (raw compliance, chance-corrected ι, same-form)? If none, the identification strategy and its measured failure are the novelty.
3. Does Zeng et al. 2025 or related work already report position effects of the 0.29–0.35 magnitude seen here?
4. Is matched-control failure (controls that saturate under composition; controls not matched on realised difficulty; vacuity/length channels in rule-based metrics — cf. IFEval loose/strict; Bean et al. 2025) already documented as an evaluation pitfall?
5. Precedents for preregistered/gated LLM-behaviour studies that stopped pre-confirmatory, and venues that accept non-identification with measured attrition.
6. Any prior report of directional/reciprocal loss asymmetry (which instruction is sacrificed) or a companion-*class* effect of the −0.5 magnitude?
7. Rule-based verifier vs human validity for exact-count constraints (the 4/44 off-by-one fail-class pattern).
